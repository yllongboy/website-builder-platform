# MVP Scope

## Goal
Build a SaaS website builder with preloaded templates.

## Customer Features
- Register / Login
- Browse categories
- Choose templates
- Create website from template
- Edit website visually
- Save drafts
- Preview website
- Publish website
- Manage billing

## Admin Features
- Manage users
- Manage categories
- Manage templates
- View websites
- View subscriptions

## Stack
- Angular + RxJS
- Java Spring Boot
- PostgreSQL
- Cloudflare R2
- Stripe
- GrapesJS
